# Steg 2d: Designval och Visuella Kontrakt

1. **Typografi & Rubriker**:
   - `index.html`: `<title>Andlighet, Vänskap och Stöd</title>`.
   - `OnboardingWizard`: Rubrik `Välj var du vill ta emot inbjudningar` i serif kursiv, utan stjärnikoner.
2. **Kortens papperskänsla**:
   - Mjuk tonad bakgrund (`bg-brand-paper/90`), rundade hörn (`rounded-3xl`), tunn ram (`border border-brand-accent/25 shadow-sm`).
3. **Knappterminologi**:
   - Skapa formulär: `Ge en inbjudan`.
   - Panelaktivering: `Slå på 'Ta emot inbjudningar'`.
   - Panelavslut: `Spara val`.
4. **Statusbrickor**:
   - `DIN INBJUDAN • FÖRBEREDS`
   - Undertext: `Förbereds för utskick i församlingsområdet`.
