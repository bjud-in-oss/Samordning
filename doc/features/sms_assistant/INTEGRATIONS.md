# Integrations for SMS Assistant

## Anslutningar & Servicar
1. **Express Backend API**:
   - `/api/incoming-sms`: Tar emot simulerat eller riktigt SMS och returnerar svarsmeddelande.
   - `/api/admin/members`: Hämtar och uppdaterar lista på administratörer och betrodda skapare.
2. **Gemini AI**:
   - Används för supportassistentens automatiska svar när relevant.
