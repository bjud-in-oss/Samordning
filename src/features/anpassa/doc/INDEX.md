# Domän: anpassa

Domänen `anpassa` äger användarinställningar, anpassningsguide (onboarding), geografi- och målgruppsurval samt det visuella temavalet (färgteman).

## Ansvar
1. Tillhandahålla interaktiv temaväljare (`ThemeSelectorSection.tsx`) för att byta applikationens färgtema (`default`, `high-contrast`, `autumn`, `spring`, `winter`).
2. Kapsla in konfigurering av geografi, språk, målgrupper och format.
3. Exponera en enhetlig fasad via `index.ts`.
