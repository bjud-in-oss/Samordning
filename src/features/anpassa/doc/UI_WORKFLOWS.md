# UI Arbetsflöden: anpassa

1. **Temaval**:
   - Användaren navigerar till sektionen "Färgtema & Visuellt uttryck" i inställningarna.
   - Ett klick på något av temakorten (`Standard`, `Högkontrast`, `Höst`, `Vår`, `Vinter`) uppdaterar omedelbart rot-elementets `data-theme`.
   - "BJUD IN"-knapp, modaler och flöden uppdateras i realtid via CSS-variablerna.
2. **Onboarding-guide**:
   - Användaren klickar sig igenom Steg 1 (Geografi) -> Steg 2 (Språk) -> Steg 3 (Organisationer) -> Steg 4 (Format).
   - Vid avslutning sparas preferenserna och användaren leds tillbaka till huvudvyn.
