# UI Workflows: `inbjudningar`

## Användarflöden
1. Flödesvy: Visar notiskort för relevanta inbjudningar i kronologisk ordning.
2. Detaljvy: Expanderar en vald inbjudan med detaljerad information och kontaktvägar.
3. Moderering: Administratörsgränssnitt för att godkänna eller avvisa väntande inbjudningar.
