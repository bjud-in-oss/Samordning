# Feature Documentation: `skapa_inbjudan`

## Overview & Scope
`skapa_inbjudan` contains the multi-step invitation creation form, AI review proposal modal, dialogs, favorite template management, and publishing state hooks.

## Public API Exports (`src/features/skapa_inbjudan/index.ts`)
- **Components**: `CreateInvitationForm`
- **Hooks**: `useInvitationForm`
- **Domain Types**: `FormState`, `AiReviewProposal`, `FavoriteItem`
